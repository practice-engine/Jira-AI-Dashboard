Self-service

The customer does it themselves in the product instead of emailing support. For example: turn off notifications, unlock a note, run a report.

Configuration

A practice admin changes a setting or list that today needs an agent or developer. For example: document types, billing rules, scheduler rules.

Automation

The system does it automatically, with no human step. For example: provision a new provider, detect and merge duplicates.
